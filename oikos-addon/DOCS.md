# Oikos — Dashboard per Home Assistant

Dashboard completamente personalizzabile per Home Assistant: card, chip, distintivi e popup componibili — senza YAML né codice.

1. **Installa** l'applicazione e clicca **Avvia**
2. Al primo avvio Oikos aggiunge automaticamente la voce **Oikos** nella barra laterale
3. **Riavvia Home Assistant** una sola volta per vedere la voce in sidebar
4. Clicca su **Oikos** nella sidebar → segui la procedura guidata per attivare la licenza

> Il riavvio di HA dopo la prima installazione è l'unica operazione manuale richiesta.

- **40 giorni di prova gratuita**, senza carta di credito
- Abbonamento **mensile o annuale** disponibile dopo il trial
- La licenza è nominale (legata alla tua email) e copre **1 installazione HA**
- Registrati su **[homeoikos.com](https://homeoikos.com)** o gestiscila dal portale integrato (Stripe o PayPal)

### 🏪 Card e Store

Lo Store integrato permette di:
- Installare le **card ufficiali** (energia, meteo, luci, stanze, EV...)
- Aggiungere **card community** da repo GitHub pubblici

## 🇬🇧 English

# Oikos — Home Assistant Dashboard

A fully composable Home Assistant dashboard: cards, chips, badges and popups — no YAML, no coding required.

### 🚀 First launch

1. **Install** the application and click **Start**
2. On first launch Oikos automatically adds an **Oikos** entry to the HA sidebar
3. **Restart Home Assistant** once to see the sidebar entry
4. Click **Oikos** in the sidebar → follow the setup wizard to activate your license

> Restarting HA after the first install is the only manual step required.

### 💳 License

- **40-day free trial**, no credit card required
- **Monthly or annual** subscription available after the trial
- The license is tied to your email and covers **1 HA installation**
- Register at **[homeoikos.com](https://homeoikos.com)** or manage it from the in-app portal (Stripe or PayPal)

### 🏪 Cards & Store

The built-in Store lets you:
- Install **official cards** (energy, weather, lights, rooms, EV charging...)
- Add **community cards** from public GitHub repositories
- Upload custom cards via **ZIP** or **private GitHub URL**
